# Visual assets

`controls.png` is generated by `tools/make_interface.py`.

`stone-paint.png` was generated with the built-in imagegen tool for this project.
It is a flat pigment/albedo image, sampled with repeating coordinates and mipmaps.
The shader combines it with geometry colors and dynamic lighting; it contains no
baked scene lighting. The shader retains procedural paint if the image is absent.

Generation prompt:

> Seamlessly tileable hand-painted stone pigment texture for a stylized illustrated 3D game, square texture asset, perfectly flat orthographic material scan. ONLY ONE continuous stone surface, no bricks, no tile grid, no object, no border. Slate grey medium values, subtly muted blue-green and mauve undertones, broad irregular matte gouache brush patches with layered hand-painted chipped edges, scattered dry-brush strokes. Moderate visual detail, controlled quiet texture with painterly shapes 30-100 pixels wide, no photographic grain, no fine noise, no deep cracks, no lighting gradient, no baked shadows, no perspective. All four edges must tile seamlessly. Color values average medium grey, not black or white, muted saturation. This is an albedo texture to wrap on individual stone blocks, not a finished room image. Hand-drawn fantasy illustration material.
