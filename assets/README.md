# Visual assets

`controls.png` is generated by `tools/make_interface.py` (legacy scene-only overlay, not used by the game).

`combat-font.png` contains PT Sans Regular for interface copy and PT Serif Regular for headings, with Cyrillic, Latin and interface symbols. Glyph advances are compiled from `src/ui_font_metrics.hpp`. To regenerate both files, run `python tools/make_combat_font.py PT_Sans-Web-Regular.ttf PT_Serif-Web-Regular.ttf` with Pillow installed. The reference TTFs are [PT Sans](https://github.com/google/fonts/blob/7af0d90b4d532ffa4b041937b560c6df4e7b1e95/ofl/ptsans/PT_Sans-Web-Regular.ttf) and [PT Serif](https://github.com/google/fonts/blob/7af0d90b4d532ffa4b041937b560c6df4e7b1e95/ofl/ptserif/PT_Serif-Web-Regular.ttf) by ParaType. Their SIL Open Font License notices are in `assets/fonts`. The five small HUD arrow and star glyphs are drawn by the atlas generator.

`team.txt` holds two lines shown on screen and in the credits: team names, then the exact topic title.

`interface-emblems.png` is a 6×4 atlas for menus, inventory, merchants and the map. `ossuary-cover.jpg` is the illustrated plate on the title screen. Both were created for this project with the built-in image generator.

All sound effects and music are synthesised in code at start-up (`src/audio.cpp`); there are no audio files.
All models are procedural geometry (`src/zone_mesh.cpp`, `src/figures.cpp`, `src/props.cpp`).

`action-icons.png` is the 4×4 painted atlas for the hotbar and class selection. Rows 1–3 follow the four ability slots of the warrior, rogue and mage. Row 4 holds the healing potion and their three portraits. Created using the built-in image generator, then packed into equal 256 px cells.

`stone-paint.png` was generated with the built-in imagegen tool for this project.
It is a flat pigment/albedo image, sampled with repeating coordinates and mipmaps.
The shader combines it with geometry colors and dynamic lighting; it contains no
baked scene lighting. The shader retains procedural paint if the image is absent.
