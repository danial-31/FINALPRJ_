# THE OSSUARY: Эшвальд — Хранитель Костей

Тактическая RPG в средневековой долине: исследование поверхности в реальном времени, пошаговые
бои на клетках с очками действий, три подземелья с боссами, добыча, ремесло, задания и сохранения.
C++17, OpenGL 3.3 Core, собственный рендерер, без игровых движков.

После обвала в старой шахте под землёй пробудился Хранитель Костей. Странник приходит в деревню
Серый Брод, ищет пропавших шахтёров, восстанавливает три печати (Паучье логово, Затопленные шахты,
Королевский склеп) и спускается в Сердце под замком Вальден.

## Сборка (Windows 10/11)

Нужны Visual Studio 2022 или новее с нагрузкой «Разработка классических приложений на C++»
(MSVC, Windows SDK, «Средства C++ CMake для Windows»), CMake 3.20+ и видеодрайвер с OpenGL 3.3 Core.
Все библиотеки лежат в `third_party/`; интернет для сборки и запуска не нужен.

В **Developer PowerShell for Visual Studio** из папки проекта:

```powershell
cmake -S . -B build
cmake --build build --config Release --parallel
.\launch-room.cmd
```

Либо запустить `build\Release\finalprj.exe` напрямую. CMake копирует рядом с exe папки
`assets/` и `shaders/` — при переносе сборки их нужно сохранить рядом с `finalprj.exe`.
`settings.ini` и папка `saves/` создаются там же при первом запуске.

Linux/macOS: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build`
(нужны компилятор C++17 и пакеты разработки X11/Wayland); проверялась только Windows-сборка.

## Управление (как в action-RPG / MOBA)

| Действие | Клавиши / мышь |
| --- | --- |
| Идти (герой сам обходит препятствия) | **ПКМ** по земле (ЛКМ тоже работает); удержание ПКМ — вести за курсором |
| Атаковать | **ПКМ** по врагу — герой подходит и бьёт автоматически |
| Подойти и взаимодействовать (NPC, сундук, святилище, рычаг) | **ПКМ** по объекту; **F** — с ближайшим объектом |
| Навыки класса | **Q W E R** — по врагу/точке под курсором (R открывается на 6 уровне) |
| Зелье · остановиться · центрировать камеру | **H** (или **1**) · **S** · **Пробел** |
| Сумка · герой и развитие · журнал · карта | **I** · **C** · **J** · **M** |
| Пауза / закрыть окно · справка | **Esc** · **F1** |
| Камера: приближение, вращение | колесо; стрелки; **СКМ** или **Alt+ЛКМ** + мышь |
| Свободная камера (WASD, Q/E, ПКМ — обзор) | **F4** |
| Перспектива / ортография | **O** |
| **Основная техника вкл/выкл** (мягкие тени PCSS + кубические карты) | **T** — состояние всегда видно справа вверху |
| Эффект миниатюры (tilt-shift) | **Y** |
| Пауза анимации (огонь, вода, облака, листва) | **P** |
| Повернуть солнце · изменить высоту | **[ ]** · **; '** |
| Скрыть HUD · снимок кадра (PPM в `captures/`) | **Tab** · **F12** |

## Что есть в игре

- **Меню** на фоне живой деревни (облака, дым из труб, огни): Продолжить (недоступно без сохранений),
  Новая игра (предупреждает о замене автосохранения), Загрузить (слоты с уровнем, местом и временем),
  Настройки, Авторы и управление, Выход.
- **Классы**: воин, разбойник, маг — свои характеристики, оружие, навык и ветка из трёх улучшений.
- **11 зон**: Серый Брод, Старая дорога, Паучья роща, Заброшенная шахта, Горный перевал, Замок Вальден;
  подземелья Паучье логово, Затопленные шахты, Королевский склеп (+ Тронный склеп), Сердце под замком.
- **Святилища**: отдых (возрождает обычных врагов), сохранение в 3 слота, перемещение между активными
  святилищами, спуск в подземелье после того, как вход найден на поверхности.
- **Бой в реальном времени**: автоатаки, снаряды, 4 навыка на класс с маной и перезарядкой,
  яд/горение/замедление/паутина/оглушение, ловушки, ядовитые лужи, строй скелетов, призраки сквозь стены.
  Враги нападают стаей и возвращаются к логову, если их увести слишком далеко.
- **Боссы**: Паучья Матка, Железный Смотритель, Павший рыцарь Вальден, Хранитель Костей. Перед ударом на
  земле появляется красная зона, которая заполняется — нужно успеть выйти; после тяжёлой атаки босс уязвим.
- **Добыча и экономика**: таблицы выпадения, 4 редкости (цвет и подпись), сравнение с надетым,
  продажа (сюжетные и уникальные вещи продать нельзя), кузнец (закалка +1..+3), травница (4 рецепта).
- **Задания**: основная линия из 11 этапов и три побочных; журнал с целью, прогрессом и наградой.
- **Сохранения**: автосохранение при переходах, активации святилища и после босса; при смерти —
  возрождение у святилища (−10% золота, прогресс сохраняется). Сохранение в бою запрещено.
- **Звук**: шаги, удары, добыча, сундуки, святилища, интерфейс, фоновые темы деревни, исследования,
  подземелий и боя — всё синтезируется в коде.

## Графика

- Перспективная камера (FOV 30°) с корректным соотношением сторон при изменении окна; изометрический ракурс.
- Шейдеры в отдельных файлах `shaders/*.vert|frag`. Ошибки чтения файла, компиляции и линковки,
  неполные framebuffer и отсутствующие текстуры выводятся в консоль с именем файла.
- Направленный свет с мягкими тенями **PCSS** (поиск блокеров → ширина полутени → PCF), две
  всенаправленные тени от ближайших жаровен (кубические карты с кэшем статичной геометрии).
- Рисованный стиль: процедурная фактура камня, клеточное освещение, цветной заполняющий свет,
  контуры по глубине, HDR, bloom, тонмаппинг ACES, небо с fbm-облаками, туман, «скверна», вода, листва.
- Depth test и отсечение задних граней для замкнутой геометрии (блоки, земля); двусторонние
  тонкие детали рисуются без отсечения.

## Проверки

```powershell
ctest --test-dir build -C Release --output-on-failure
```

- `tactical_combat` — правила боя, обозначенные атаки боссов, уклонение, уязвимость, таланты.
- `campaign` — инвентарь, экономика, сохранение/загрузка, повреждённые сохранения, правила смерти и
  **автоматическое полное прохождение сюжета каждым классом** (бот играет все бои и боссов).
- `crypt_room` — `finalprj --smoke-test`: скрытое окно, сценарий через настоящий код кликов
  (староста → святилище → выход → бой), отрисовка всех 11 зон, изменение размеров окна, ошибки OpenGL.
- Тесты геометрии, коллизий и анимации исходной сцены.

Дополнительно: `finalprj --benchmark` пишет `benchmark.csv` (FPS при 1280×720 с техникой и без);
`finalprj --zone lair --battle --capture shot.ppm` сохраняет кадр выбранной зоны.

## Структура

- `src/combat.*` — правила боя, ИИ, боссы. `src/world.hpp` — сетка зон.
- `src/rpg.*` — кампания: предметы, задания, NPC, святилища, сохранения. `src/zone_data.inc` генерируется
  из `tools/zones.py` (карты зон с проверкой достижимости).
- `src/renderer.*` — проходы рендера. `src/zone_mesh.cpp`, `src/figures.cpp` — процедурная геометрия.
- `src/app.cpp`, `src/app_ui.cpp`, `src/ui.hpp` — приложение, ввод, интерфейс. `src/audio.cpp` — звук.
- `shaders/` — GLSL. `assets/` — атлас шрифта, текстура камня, `team.txt` (команда и тема на экране).
